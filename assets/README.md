# Assets Directory

This directory contains all static assets for the Sleep Persona app.

## Required Assets

### App Icons
- `icon.png` - 1024x1024px app icon
- `adaptive-icon.png` - 1024x1024px adaptive icon (Android)
- `favicon.png` - 48x48px favicon (web)

### Splash Screen
- `splash.png` - 1242x2436px splash screen image

### Images
Place any additional images needed for the app in subdirectories:
- `images/onboarding/` - Onboarding screen illustrations
- `images/personas/` - Persona avatars and icons
- `images/routines/` - Routine step icons

### Fonts (Optional)
If using custom fonts, place them in:
- `fonts/` - Custom font files (.ttf, .otf)

## Design Guidelines

### Icon Requirements
- Simple, recognizable design
- Dark background compatible
- Sleep/night theme
- Indigo primary color (#6366F1)

### Splash Screen
- Dark background (#0F0F1E)
- App logo centered
- Minimal design
- Loading indicator optional
